# 🚌 UrbanTransit — Интеллектуальная система городского транспорта

Современное веб-приложение для планирования маршрутов и мониторинга расписания городского общественного транспорта в режиме реального времени. Проект сочетает высокопроизводительный RESTful API на платформе **ASP.NET Core 10.0**, премиальный пользовательский интерфейс на **React 19** с адаптивным темным оформлением, а также набор **Python-скриптов** для агрегации и парсинга транспортных данных.

---

## 🌟 Полный функционал системы

### 🗺️ Интеллектуальный маршрутизатор (Route Planner)
Поиск оптимального пути между выбранными остановками.
- Отображение точного времени в пути.
- Расчет времени до ближайшего отправления транспорта относительно текущего времени.
- Визуализация промежуточных остановок с поминутной детализацией прибытия.

### ⏱️ Интерактивные расписания (Schedules)
Полный список всех городских маршрутов с фильтрацией по видам транспорта:
- **Автобусы (Bus)**
- **Трамваи (Tram)**
- **Троллейбусы (Trolleybus)**
- **Маршрутные такси (Minibus)**
- Детальный поминутный график отправления для каждой остановки по дням и часам.

### 📍 Информационные панели остановок (Stop Details)
Сводная информация по каждой физической остановке города:
- Точный адрес и географическое направление движения.
- Список всех проходящих маршрутов.
- Интерактивное табло ближайших прибытий.

### 💖 Персональный раздел (Favorites)
Возможность сохранять часто используемые элементы для быстрого доступа без поиска:
- Избранные маршруты и остановки.
- Кастомные точки назначения с персонализированными иконками.

### ⚠️ Служба уведомлений (Notifications)
Раздел оперативного информирования пассажиров о состоянии транспортной сети.
- 🔴 **Сбои в движении (Disruptions):** ДТП, перекрытия дорог с указанием затронутых маршрутов.
- 🟡 **Задержки (Delays):** Отклонения от графика из-за пробок.
- 🔵 **Технические работы (Maintenance):** Плановый ремонт.
- 🟢 **Общая информация (Info):** Временные переносы остановок.

### 🔐 Портал администратора (Admin Dashboard)
Защищенная панель управления для диспетчеров и администраторов транспортной системы:
- Авторизация на базе **JWT Bearer** с шифрованием паролей через **BCrypt**.
- Полнофункциональный интерфейс **CRUD** для управления справочниками:
  - Создание, редактирование и удаление остановок.
  - Управление маршрутами и схемами движения.
  - Настройка расписаний рейсов.
  - Управление сервисными уведомлениями.

### ⚙️ Парсинг и обработка данных
Комплекс Python-скриптов для сбора и агрегации расписаний:
- Извлечение данных из сырых HTML и TXT-выгрузок.
- Автоматический расчет временных интервалов и смещений между остановками.
- Генерация нормализованного `clean_db.json`, который автоматически импортируется сервером.

## 🎨 Дизайн и UI-система

Интерфейс спроектирован по кастомному руководству **Corporate Modern в Dark Mode** (находится в `stitch_/urban_transit_system/DESIGN.md`):
- **Цветовая палитра:** Глубокий темный фон (`#121414`) дополнен выразительными акцентами — **терракотовым оранжевым** (`#ffb599`), **приглушенным серо-коричневым** (`#e7bdae`) и **оливково-золотым** (`#d4c78e`).
- **Скругления (Shapes):** Применяется мягкая геометрия со скруглениями 8px для стандартных кнопок, 16px (1rem) для карточек.
- **Типографика:** Использование современного геометрического шрифта **Plus Jakarta Sans** обеспечивает превосходную читаемость.
- **Интерактивность:** Плавные микро-анимации (`fade-in`, `slide-up`), эффекты размытия фона (`backdrop-blur`).

## 🚀 Инструкция по установке и локальному запуску

Для запуска проекта потребуются **.NET SDK 10.0**, **Node.js 18+** и (опционально) **Python 3** для работы с данными.

### Шаг 1. Запуск Backend (API)
1. Откройте терминал и перейдите в папку с серверной частью:
   ```bash
   cd TransitApi
   ```
2. Запустите веб-сервер:
   ```bash
   dotnet run
   ```
   Сервер будет доступен по адресу `http://localhost:5000`. Swagger API: `http://localhost:5000/swagger/index.html`. При первом запуске БД `transit.db` будет автоматически создана и инициализирована тестовыми данными.

### Шаг 2. Запуск Frontend (React Client)
1. Откройте второй терминал и перейдите в папку клиента:
   ```bash
   cd transit-client
   ```
2. Установите зависимости:
   ```bash
   npm install
   ```
3. Запустите сервер разработки Vite:
   ```bash
   npm run dev
   ```
   Доступ: `http://localhost:5173`. CORS настроен, Vite проксирует запросы на `/api` в backend.

### Доступ администратора (Admin Dashboard)
