# 🚌 UrbanTransit — Интеллектуальная система городского транспорта

[![.NET Core](https://img.shields.io/badge/.NET-8.0-blueviolet.svg?style=flat-square&logo=dotnet)](https://dotnet.microsoft.com/)
[![React](https://img.shields.io/badge/React-19.0-blue.svg?style=flat-square&logo=react)](https://react.dev/)
[![TailwindCSS](https://img.shields.io/badge/TailwindCSS-v3.x-38bdf8.svg?style=flat-square&logo=tailwindcss)](https://tailwindcss.com/)
[![SQLite](https://img.shields.io/badge/SQLite-3-003b57.svg?style=flat-square&logo=sqlite)](https://www.sqlite.org/)
[![Vite](https://img.shields.io/badge/Vite-8.x-646cff.svg?style=flat-square&logo=vite)](https://vite.dev/)

Современное веб-приложение для планирования маршрутов и мониторинга расписания городского общественного транспорта в режиме реального времени. Проект сочетает высокопроизводительный RESTful API на платформе **ASP.NET Core** и премиальный пользовательский интерфейс на **React 19** с адаптивным темным оформлением.

---

## 🌟 Основные возможности

### 🗺️ Интеллектуальный маршрутизатор (Route Planner)
Поиск оптимального пути между выбранными остановками.
- Отображение точного времени в пути.
- Расчет времени до ближайшего отправления транспорта относительно текущего времени.
- Визуализация промежуточных остановок с поминутной детализацией прибытия.

### ⏱️ Интерактивные расписания (Schedules)
Полный список всех городских маршрутов с фильтрацией по видам транспорта:
- **Автобусы (Bus)**
- **Трамваи (Tram)**
- **Троллейбусы (Trolleybus)**
- **Маршрутные такси (Minibus)**
Детальный поминутный график отправления для каждой остановки по дням и часам.

### 📍 Информационные панели остановок (Stop Details)
Сводная информация по каждой физической остановке города:
- Точный адрес и географическое направление движения.
- Список всех проходящих маршрутов.
- Интерактивное табло ближайших прибытий.

### 💖 Персональный раздел (Favorites)
Возможность сохранять часто используемые элементы для быстрого доступа без поиска:
- Избранные маршруты и остановки.
- Кастомные точки назначения с персонализированными иконками (например, «Дом», «Работа» и др.).

### ⚠️ Служба уведомлений (Notifications)
Раздел оперативного информирования пассажиров о состоянии транспортной сети. Уведомления делятся на типы:
- 🔴 **Сбои в движении (Disruptions):** ДТП, перекрытия дорог с указанием затронутых маршрутов.
- 🟡 **Задержки (Delays):** Отклонения от графика из-за пробок или погодных условий.
- 🔵 **Технические работы (Maintenance):** Плановый ремонт путей с предоставлением компенсационных маршрутов.
- 🟢 **Общая информация (Info):** Временные переносы остановок и изменения правил проезда.

### 🔐 Портал администратора (Admin Dashboard)
Защищенная панель управления для диспетчеров и администраторов транспортной системы:
- Авторизация на базе **JWT Bearer** с шифрованием паролей через **BCrypt**.
- Полнофункциональный интерфейс **CRUD** для управления справочниками:
  - Создание, редактирование и удаление остановок.
  - Управление маршрутами и схемами движения.
  - Настройка расписаний рейсов.
  - Публикация и архивирование сервисных уведомлений.
- Адаптивные формы с валидацией данных.

## 🚀 Инструкция по установке и локальному запуску

Для успешного запуска проекта вам потребуются установленные **.NET SDK 8.0** и **Node.js LTS (версии 18 или новее)**.

### Шаг 1. Запуск Backend (API)

1. Откройте терминал и перейдите в папку с серверной частью приложения:
   ```bash
   cd TransitApi
   ```
2. Восстановите NuGet-пакеты:
   ```bash
   dotnet restore
   ```
3. Запустите веб-сервер:
   ```bash
   dotnet run
   ```
   Сервер запустится по адресу `http://localhost:5000`. Вы можете проверить работоспособность API и изучить документацию Swagger, перейдя по адресу:
   👉 **`http://localhost:5000/swagger/index.html`**

---

### Шаг 2. Запуск Frontend (React Client)

1. Откройте второй терминал и перейдите в папку с клиентской частью приложения:
   ```bash
   cd transit-client
   ```
2. Установите необходимые NPM-зависимости:
   ```bash
   npm install
   ```
3. Запустите сервер разработки Vite:
   ```bash
   npm run dev
   ```
4. После успешного запуска перейдите по указанному в консоли локальному адресу:
   👉 **`http://localhost:5173`** (или указанному Vite порту).

> [!NOTE]
> Все запросы к `/api/*` автоматически проксируются сервером Vite на `http://localhost:5000/api/*` благодаря преднастроенному файлу конфигурации [vite.config.js](file:///c:/Users/User/Desktop/Projects/FOUR_P/transit-client/vite.config.js#L6-L13). Никаких дополнительных настроек CORS для локальной среды выполнять не требуется.

## 🛠️ Стек технологий

### Backend
- **ASP.NET Core Web API 8.0**
- **Entity Framework Core 8.0** (Entity Framework Core SQLite)
- **SQLite Database**
- **BCrypt.Net-Next** (Хеширование паролей пользователей)

### Frontend
- **React 19.x** (Библиотека интерфейсов)
- **Vite 8.x** (Быстрый инструмент сборщика)
- **Tailwind CSS v3** (Utility-first CSS фреймворк)
- **React Router Dom v7** (Клиентская маршрутизация)
- **Axios** (Клиент HTTP-запросов)
- **Material Symbols Outlined** (Премиальный пакет иконок от Google)
